# Conhecimento — rea

Pesquisado em 2026-10-15. Não é aconselhamento jurídico; na dúvida, recuse.

1. **Exceção de interoperabilidade nos EUA (17 U.S.C. §1201(f)) é estreita:** só para quem tem direito legal de usar a cópia, só para identificar o necessário à interoperabilidade, e sem infringir.
   Fonte: https://lists.opensource.org/pipermail/license-discuss_lists.opensource.org/2015-March/019061.html
2. **Na UE (Diretiva 2009/24/CE, art. 6) a descompilação sem autorização só vale se for indispensável para interoperar;** não pode servir para criar produto concorrente nem para publicar o que foi obtido.
   Fonte: https://jde.pubsys.hbz-nrw.de/index.php/jipitec/article/view/1031
3. **Precedente: desmontar código pode ser uso legítimo quando é o único jeito de obter elementos funcionais para interoperar** (Sega v. Accolade).
   Fonte: https://eff.org/files/filenode/Chamberlain_v_Skylink/20040401_skylink_appeal_amicus.pdf
4. **Licença manda.** Código aberto: leia a licença do projeto; software próprio: registre que é seu; terceiros: só com autorização escrita.
   Fonte: https://lists.opensource.org/pipermail/license-discuss_lists.opensource.org/2015-March/019082.html
5. **Relatório rastreável:** pergunta, alvo, base de autorização, método, achados com evidência (arquivo, offset, símbolo), fatos separados de hipóteses, dados sensíveis mascarados. (Prática interna da Real Corp.)
