# Conhecimento — organizador

Pesquisado em 2026-10-15. Leia só quando precisar de detalhe.

1. **Critério de aceitação em Dado / Quando / Então.** Dado = estado inicial; Quando = a ação; Então = o resultado verificado. Escreva o "pronto" assim, de forma que dê para testar.
   Fonte: https://automationpanda.com/2017/01/26/bdd-101-the-gherkin-language/
2. **Cenários curtos: 3 a 5 passos.** Cenário longo perde valor como especificação; se passar disso, divida.
   Fonte: https://cucumber.io/docs/gherkin/reference/ (cópia: https://cloud.r-project.org/web/packages/cucumber/vignettes/reference-gherkin.html)
3. **Registro de riscos com campos fixos:** ID, descrição, probabilidade, impacto, pontuação (prob. × impacto), resposta e dono.
   Fonte: https://www.techademy.com/pmp-risk-register-template
4. **Todo risco tem dono e uma resposta:** evitar, mitigar, transferir ou aceitar.
   Fonte: https://projectmanagementacademy.net/resources/blog/risk-register-in-project-management/
5. **Ligue o risco ao passo do plano** (como o número da EAP/WBS), para saber qual passo ele ameaça.
   Fonte: https://www.projectmanagement.com/deliverables/387312/risk-register-template

Como aplicar: cada passo do PLANO tem 1 objetivo, dono, critério Dado/Quando/Então; os riscos apontam para o número do passo.
